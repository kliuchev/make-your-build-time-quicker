01 / Type checking

What changed
in Swift 6.4

The compiler

Rules out unsuitable overloads earlier.

Narrows down possible types and recomputes only affected choices.

SwiftUI in Xcode 27

ContentBuilder reduces the alternatives in builder expressions.

Also works with older deployment targets.

Complex expressions and error diagnostics can still be expensive.

01 / Type checking

Even so…

Type inference problems
still remain.

Find slow expressions in the build log.

Give intermediate values explicit types.

Split long expressions into smaller pieces.

02 / Compile cache

Two settings in Xcode

In your project’s .xcconfig or Build Settings

COMPILATION_CACHE_ENABLE_CACHING = YES
COMPILATION_CACHE_ENABLE_DIAGNOSTIC_REMARKS = YES

First build

Compiles and stores the result.

Next build

Reuses it when the inputs match.

Check the build log for cache hits. New code, flags or SDKs can cause misses.
